# Project Purpose

Hercules is a self-contained multi-account Binance USDT-M Futures system with deterministic historical backtesting, a Rust decision core, paper/testnet/real execution adapters, Supabase authentication/storage, and a FastAPI browser dashboard.

Configured assets are BTCUSDT, ETHUSDT, SOLUSDT, and XRPUSDT. Real execution remains an operator-controlled deployment action; see [[Known Risks]].
